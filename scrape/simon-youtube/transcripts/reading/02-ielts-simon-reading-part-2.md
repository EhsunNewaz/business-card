## Description

```
This video by IELTS Simon provides a comprehensive guide on mastering gap-fill questions for the IELTS Reading test. The lesson emphasizes effective exam techniques to save time and improve accuracy.

Key Exam Techniques (0:00 - 3:50)
Don't read the passage first: Start directly with the title, then move immediately to the questions to avoid wasting time.
Keyword Technique (The Core Strategy): Underline important words in the questions, then search for those exact words or synonyms within the passage (0:30-1:25).
Read at normal speed: Avoid skimming or scanning unless you are specifically looking for simple data like names or numbers (1:37-2:47).
Skip difficult questions: If a question is too hard, move on and return to it at the end to ensure you don't lose time on easy points (2:50-3:26).
Types of Gap-Fill Questions (7:49 - 20:00)
The instructor categorizes gap-fill tasks into four main types and provides walkthroughs for each:

Sentence completion: Filling gaps with words directly from the text (4:26-7:06).
Diagram labeling: Using visual guides to locate information (8:04-10:55).
Box/List selection: Choosing the best-fitting word from a provided list, often requiring synonym identification (11:42-16:32).
Table completion: Organizing information into a table format (17:06-19:59).
Study Tip (20:53 - 21:58)
IELTS Simon recommends that when practicing at home, students create a keyword table to track synonyms found in the passage (e.g., matching "shaded" with "damp" or "never parasitic" with "not classed as parasites"). This practice significantly improves your ability to recognize how questions are paraphrased in the actual exam.
```
