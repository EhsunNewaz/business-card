Key Techniques for Matching Names:

Keyword Analysis (1:07 - 1:30): Begin by underlining keywords in the question statements—focusing on nouns and verbs—to identify the core meaning before looking at the passage.
Name Scanning (1:32 - 2:18): Scan the passage specifically to find all the names in the list. Highlighting or circling them helps you see exactly where they appear, as they are distinct and cannot be replaced by synonyms.
Shortest Description First (2:19 - 3:15): Start by examining the name with the least amount of information written about it. It is often faster and easier to match a name with a concise description.
Comparison (3:16 - 4:05): Read the specific sentences surrounding that name and compare the main ideas against the question statements to find the correct match.
