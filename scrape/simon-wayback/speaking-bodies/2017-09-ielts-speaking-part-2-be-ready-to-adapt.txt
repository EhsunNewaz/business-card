If you've prepared ideas for the [six main topic areas](https://ielts-simon.com/ielts-help-and-english-pr/2012/09/ielts-speaking-part-2-main-topics.html) in part 2, are you also ready to adapt those ideas if the topic is slightly different?

For example, if you've prepared a description of a family member, would you be able to use some of the same ideas to describe a famous person? Or if you've prepared a description of a film, would you be able to use some of the same ideas to describe a book or an advertisement?

_**My tip:**_ when preparing the topics, think about ['theme language'](https://ielts-simon.com/ielts-help-and-english-pr/2016/10/ielts-speaking-part-2-prepare-a-theme.html) and then think about how you could adapt your ideas for similar tasks.
