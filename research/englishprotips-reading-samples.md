## 2) Introduction to the reading test (25 min, full)

- Video alt: https://iframe.mediadelivery.net/play/220384/4610276c-24c8-479d-aa7c-445adf182b7c
- **Quiz (9 Q):** duration? → 60 min · passages? → 3 · same A/G? → no · questions? →
  40 · negative marking? → no · write on paper? → yes · all caps? → your choice ·
  spelling? → yes · all in order? → no.
- **Facts:** 40 Qs, 1 mark each, no negatives, caps allowed, NO transfer time, A≠G.
- **9 Tips (full):** 1. glance → skim (mark names/dates/theories, map paragraphs) →
  tackle · 2. skip unknowns, return later (race against time) · 3. learn each type
  (course covers all) · 4. speed reading (questions first; don't subvocalise/re-read
  except for detail) · 5. time split 15/20/25 (some do Section 3 first) · 6. spelling
  (computer test: copy-paste answers!) · 7. guess — leave MCQ/TFNG last (25%+ odds) ·
  8. practice like band-7 scorers (some did 100+ tests) in 3 stages: Skill Dev
  (1 passage, untimed, error log + vocab) → Reading Practice (timed full tests,
  track progress) → Full Test Practice (L+R+W same day, stamina) · 9. extensive
  reading for fun, below-level graded readers (Penguin Readers link).
- **FAQ (4):** 15/20/25 split · caps yes (clearer) · pencil for R+L · order depends
  on type.

## 3) Multiple choice (30 min, full)

- Video alt: https://iframe.mediadelivery.net/play/220384/9b970d83-c341-4cd6-a7b5-8f938819b90f
- **Tasks (3):** 1-from-4 · 2-from-5/6 · 3-from-6. Example image (Cambridge past papers).
- **Strategy (6 steps):** 1. glance to ID type · 2. skim passage first, underline
  names/dates/theories · 3. read ALL questions + options, underline · 4. answer each
  (watch the two similar options; locate + read carefully) · 5. skip unknowns —
  answers in order, so bracket Q2 between Q1 and Q3 · 6. never blank — guess.
- **Tip:** leave MCQ last if short on time (best guessing odds vs word-from-text types).
- **Practice:** Older people in the workforce (×2) · The Leader of the Pack
  (englishprotips.com/reading_questions/…).
