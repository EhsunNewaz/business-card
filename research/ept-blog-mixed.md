## 4. Matching Headings in IELTS Reading (2024-02)
URL: https://ielts.englishprotips.com/matching-headings-in-ielts-reading/
Stub page; practice test in open PDF 📄 https://media.publit.io/file/CoursePDF/IELTS-Reading-Matching-Headings.pdf (fetched ✅):
Passage "Density and Crowding" (A–G): A = 3 trends → crowding (pop +1.4M/wk, urbanisation, communication explosion); B = density (physical count) vs crowding (psychological pressure — frontiersman vs suburbanite); C = Calhoun 1962 rats (50-capacity → 80: harems, nest abandonment, mortality↑, aggression, sexual variation); D = follow-ups: SOCIAL density (interactions) predicts harm, not spatial; E = why unpleasant: stimulus overload (harried mother), no privacy; F = field studies: prisons (male aggression; gender space needs), attraction↓, helping↓ (diffusion of responsibility); G = coping: control↓ = crowding↓; liked company; social withdrawal (gaze aversion, closed body language).
Q1–7 key (my match): A→iv / B→vii / C→x / D→i / E→vi / F→ii / G→viii (unused: iii, v, ix).

## 6. Should You Pay for EOR? (2021-10)
URL: https://ielts.englishprotips.com/should-you-pay-for-eor/
EOR = paid remark by senior examiner blind to original marks (details: ielts.org/results). Most EORs DON'T change score (British Council); L/R almost never change (no interpretation). Apply ONLY if ALL answers Yes:
Academic T1: finished? / all categories? / intro? / overview? / logical paras? / comparisons? / >150 words? / spelling?
General T1: finished? / correct style? / greeting+opener+closer+sign-off? / bullets in separate paras? / all parts of each bullet? / ≥2 sentences/bullet? / >150? / spelling?
T2: finished? / clear intro opinion? / logical paras? / developed ideas + examples? / conclusion restates opinion? / no new ideas in conclusion?
Any No/unsure → retake instead. (Disclaimer: decision yours; EPT not liable.)
