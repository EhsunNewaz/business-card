## 1. Band 9 in IELTS Writing — Laziz (2024-06)
URL: https://ielts.englishprotips.com/band-9-in-ielts-writing/
📄 Laziz's essay: https://ielts.englishprotips.com/wp-content/uploads/2024/06/Band-9-Essay-from-Laziz.pdf (essay text lives in PDF, not on page)
Tips: research a lot; read more than you write; understand what band descriptors REALLY mean; drop the mental ceiling; improvement takes time; examiner-patterns become subconscious after checking 500–1000 essays.
Before writing: read carefully + highlight key points; plan ideas 5–7 min.
Intro (3–4 min): don't overthink paraphrase; clear position; brief main ideas; nothing special.
Body: 3 paragraphs — one concedes a disagreement point then refutes with strong counter-argument; self-check vs band descriptors.
Conclusion (1–2 min): clear position + summary, NO new ideas.
Editing/proofreading = MUST for 8–9 (spelling, word formation, punctuation, tenses, prepositions).

## 9. Top 8 Reasons why you CAN'T get Band 7+ in IELTS Writing (2023-07)
URL: https://ielts.englishprotips.com/top-8-reasons-why-you-cant-get-band-7-in-ielts-writing/
Two root causes: level not good enough OR exam technique not good enough.
1. Insufficient vocabulary → learn IELTS writing vocab from model essays (read → gap-fill → record → reuse).
2. Grammar accuracy (most common blocker; one criterion at 6 = overall 6.5) → get essays assessed (ieltstutors.org) or free checkers (writer.com, Grammarly, ChatGPT — no real band score); top error areas: articles, subject-verb agreement, tenses.
3. Misunderstanding the question → read carefully; study model essays.
4. No position in intro → opinion questions need position in intro AND conclusion (2 model intros given: children-later adv/dis; traffic congestion solutions). Tip: experiment with writing intro AFTER the essay.
5. Undeveloped ideas → topic sentence + example/development + link back to Q.
6. Illogical paragraphs → intro + ≥2 body + conclusion; one idea per body para; Furthermore/In addition/However.
7. New ideas in conclusion → restate ideas + opinion only.
8. Running out of time → timed practice; ≥4 min checking; computer-based test; fixed structures per type.
Quiz (8Q T/F): False / True / True / False / True / False / False ("conlcusion" sic) / True.

## 16. Don't Make These 5 Mistakes in Task 1 (2021-10)
URL: https://ielts.englishprotips.com/dont-make-these-5-mistakes-in-task-1/
1. Wrong overview (B7 needs "clear overview of main trends/differences/stages"): analyse 2–4 min; overview FIRST; start "Overall,"; cover all categories' trends; learn per-graphic-type overviews (table/process/map/future).
2. Missing a category (= TA 5): count categories; superlatives; group (increasers vs decreasers); predictions; all process stages; map differences.
3. Illogical paragraphs: ≥2 body paras; group while analysing; no 1-sentence paras.
4. Repeated sentence structures (B7 = "variety of complex structures"): non-defining relative clauses; passives; before/after subordinates; past perfect; subordinate connectors.
5. Explaining data: instruction says summarise+compare — reasons/explanations LOSE marks.
Quiz (10Q, same as vocab post #19): True / Overall, / Band 6 / multi (overview+order+superlatives, NOT reasons) / True / False / seen / experienced / which / reducing.
Cloze = same 253-word population model answer (Overall/reduction/albeit/meaning/inhabitants/respectively/each/experienced/which/Finally).
