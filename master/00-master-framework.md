# A Complete Guide to IELTS Preparation for Bangladeshi Students

> ওয়ার্কিং টাইটেল (আগের): IELTS Complete Solution — Master Framework (চার্ট/আর্কিটেকচার)

আগে স্ট্রাকচারটা বুঝে নিই। আপনি ইংরেজিতে ভালো, ১ সপ্তাহ প্রিপ নেবেন, টেস্ট দেবেন। তাই আপনার দরকার "ইনক্রিমেন্টাল ডিফিকাল্টি কী, পাসেজ নাকি কোশ্চেন আগে, কতগুলো কোশ্চেন টাইপ, ওভারঅল স্ট্রাটেজি + কোশ্চেন-ওয়াইজ স্ট্রাটেজি" — একদম ক্লিয়ার ডক। নিচে ওই কমপ্লিট সিস্টেম।

---

## ১) কনটেন্ট আর্কিটেকচার (৩ টায়ার)

| টায়ার | কী | উদ্দেশ্য |
|-------|----|---------|
| **Tier 0 — Master Write-up** | `master/01..04` (এই ফোল্ডার) | অথরিটেটিভ নলেজ বেস। সোর্স অফ ট্রুথ। "১০-মিনিট গাইড" স্টাইল, কোটেড ব্যান্ড ডিস্ক্রিপ্টর + কোশ্চেন-ওয়াইজ স্ট্রাটেজি। |
| **Tier 1 — Derived Blog** | `blogs/01..04` | ইঞ্গেজিং, কলোকোয়াল বাংলা ব্লগ। মাস্টার থেকে স্পিন-অফ। পাবলিশড কনটেন্ট। |
| **Tier 2 — Template** | `templates/blog-template.md` | নতুন ব্লগ দ্রুত বানানোর স্কেলটন। |

সিস্টেমটা এইটাই: **মাস্টার ডক লিখুন → ওখান থেকে ব্লগ স্পিন করুন → টেমপ্লেট দিয়ে স্কেল করুন।**

---

## ২) স্কোপ ম্যাপ — IELTS Jacky-এর সাথে মিলিয়ে

IELTS Jacky প্রতি মডিউলে মাল্টি-লেসন দেয়। আমরা সেই স্কোপ কভার করছি:

| মডিউল | Jacky-এর স্কোপ | আমাদের Master Doc-এ কভার |
|-------|----------------|----------------------------|
| **Writing** | ৫ Task 2 type (Opinion, Discussion, Problem-Solution, Adv/Disadv, Double-Q) + Task 1 (Academic 7 chart type, General letter) + planning/intro/body/conclusion | ✅ সব + ব্যান্ড ডিস্ক্রিপ্টর কোট |
| **Speaking** | Part 1/2/3 + টপিক লিস্ট + ফ্লুয়েন্সি ট্রিকস | ✅ Part-wise + PEEL + থিংক-ফাস্ট |
| **Reading** | সব কোশ্চেন টাইপ + matching + T/F/NG | ✅ ১১ অফিশিয়াল টাইপ কোশ্চেন-ওয়াইজ |
| **Listening** | ৪ সেকশন + কোশ্চেন টাইপ | ✅ সেকশন-ওয়াইজ + প্রেডিকশন |

## ৩) অথরিটেটিভ সোর্স স্ট্যাক

কোনো কথা আমার মুখে বানানো না — প্রতিটা স্ট্রাটেজি রিলায়েবল সোর্স থেকে:

1. **Official IELTS Band Descriptors (Public Version)** — Cambridge ESOL, British Council, IDP। ব্যান্ড ৭ আসলে কী দেখতে তার এক্স্যাক্ট কোট দিচ্ছি মাস্টার ডকে।
2. **Pauline Cullen** — *The Official Cambridge Guide to IELTS* + *The Key to IELTS Success* (ফ্রি PDF, keytoielts.com) + *Cambridge Vocabulary for IELTS*। তাঁর কোর ইনসাইট: **micro-skills** (প্রতিটা কোশ্চেন টাইপের ছোট ছোট স্কিল), **active vocabulary**, আর **collocation**।
3. **Chris Pell (IELTS Advantage)** — "Coffee Shop Method" (আইডিয়া জেনারেট করার রিল্যাক্সড পদ্ধতি) + লিসেনিং ১-ঘণ্টা মাস্টারক্লাস (prediction, background noise-এ প্র্যাকটিস)।

## ৪) কার জন্য + ১-সপ্তাহ ওভারভিউ

**ফর হুম:** ইংরেজিতে ভালো, টেস্ট স্ট্রাটেজি আর এগজাম টেকনিক দরকার, ল্যাঙ্গুয়েজ বেসিক না।

**১ সপ্তাহ প্ল্যান (ট্যাকটিক্যাল):**
- **দিন ১:** Writing master পড়ুন → ৫ essay type + Task 1 overview রপ্ত।
- **দিন ২:** Speaking master → PEEL + Part 2 ন্যারেটিভ শেপ প্র্যাকটিস।
- **দিন ৩:** Reading master → ১১ কোশ্চেন টাইপ + টাইম স্প্লিট।
- **দিন ৪:** Listening master → prediction + সেকশন-ওয়াইজ।
- **দিন ৫:** একটা ফুল মক (সব মডিউল)।
- **দিন ৬:** ভুল রিভিউ (ব্যান্ড ডিস্ক্রিপ্টর দিয়ে চেক)।
- **দিন ৭:** রিল্যাক্স + স্পেলিং লিস্ট ঝালানো।
