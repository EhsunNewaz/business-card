# ১০-মিনিট গাইড টু IELTS Reading — Master Write-up

রিডিং আসলে "পড়ার" পরীক্ষা না, "খোঁজার" পরীক্ষা। আপনি ইংরেজিতে ভালো হলে বাধা শুধু **টাইম + স্ট্রাটেজি**। নিচে মাস্ট-নো ডক।

---

## কনটেক্সট: ফরম্যাট

৬০ মিনিট, ৩ passage, ৪০ কোশ্চেন। Academic (৩ লম্বা টেক্সট) vs General (সহজ টেক্সট কিন্তু একই ব্যান্ড পেতে বেশি correct লাগে)।

**ব্যান্ড কাটা (approx, Academic):** ৩০-৩২ = ৭.০, ৩৩-৩৪ = ৭.৫, ৩৫-৩৬ = ৮.০। General-এ ৭.০ পেতে ৩৪-৩৫টা লাগে।

---

## মাস্ট-নো ফ্যাক্টস

1. **Incremental difficulty:** Passage 1 সহজ → Passage 3 কঠিন। ক্রমশ কঠিন হয়।
2. **Question first, not passage:** পুরো passage পড়বেন না। প্রশ্ন → keyword → scan।
3. **Order:** বেশিরভাগ টাইপে কোশ্চেন টেক্সটের অর্ডারে থাকে (matching/which-paragraph বাদে)।
4. **Synonym:** উত্তর টেক্সটে অন্য শব্দে থাকে ("increase" → "rise")।
5. **Transfer:** শেষ ২-৩ মিনিট answer sheet-এ লিখুন।

---

## ওভারঅল ট্যাকলিং স্ট্রাটেজি (টাইম স্প্লিট)

Pauline Cullen-এর ইনসাইট: "you cannot guess the answer without reading" → স্কিম-স্ক্যান রপ্ত করুন, vocabulary matching-এর উপর ভরসা করবেন না।

| পাসেজ | সময় | কৌশল |
|-------|------|-------|
| **1** | ১৫ মিনিট | সহজ, দ্রুত শেষ করুন |
| **2** | ২০ মিনিট | মাঝারি |
| **3** | ২৫ মিনিট | কঠিন, বেশি সময় |
| **Transfer** | ২-৩ মিনিট | শেষে রাখুন |

**স্টেপ ১ — Skim (২-৩ মিনিট):** heading, first/last line → টেক্সট কী নিয়ে বুঝুন।
**স্টেপ ২ — Question:** keyword চিহ্নিত (names, numbers, nouns)।
**স্টেপ ৩ — Scan:** keyword বা synonym খুঁজুন, উত্তর বের করুন।

---

## কোশ্চেন-টাইপ-ওয়াইজ স্ট্রাটেজি (১১ অফিশিয়াল টাইপ)

**১. Multiple Choice:** keyword খুঁজুন, distractors (কাছাকাছি কিন্তু ভুল) সাবধানে। একাধিক উত্তর হলে সব হুঁজুন।

**২. True / False / Not Given:** টেক্সটের সাথে মিল = True; উল্টো = False; বিষয় নাই = Not Given। বাইরের জ্ঞান ব্যবহার না।

**৩. Yes / No / Not Given:** লেখকের মতামতের জন্য (২-এর মতোই, কিন্তু writer's claims)।

**৪. Matching Information:** কোন paragraph-এ info আছে খুঁজুন। অর্ডারে নাই → পুরো টেক্সট স্ক্যান।

**৫. Matching Headings:** প্রতি paragraph-এর মেইন আইডিয়া (full paragraph পড়ুন, শুধু first line না)। example heading আগেই বাদ দিন।

**৬. Matching Features:** A-F list (people/things) মিলান। নাম/তারিখ scan করুন।

**৭. Matching Sentence Endings:** grammar + meaning মেলান। একবার এক সেন্টেন্স পড়ে সব ending চেক করবেন না, বরং ending থেকে keyword খুঁজুন।

**৮. Sentence Completion:** word limit মানুন (NO MORE THAN TWO WORDS)। টেক্সট থেকে exact word নিন।

**৯. Summary / Note / Table / Flow-chart Completion:** gap-এর আগে-পরে keyword দিয়ে টেক্সটে খুঁজুন। লজিক্যাল ফ্লো দেখুন।

**১০. Diagram Label Completion:** ডায়াগ্রামের লেবেল + টেক্সটের বর্ণনা মেলান।

**১১. Short-Answer Questions:** প্রশ্নের wh-word (what/why/who) দেখুন, word limit মানুন।

---

## টিপস অ্যান্ড ট্রিকস

- **Don't read everything:** skim + scan = টাইম বাঁচে।
- **Keywords = names, numbers, dates, capitals** — সহজে চোখে পড়ে।
- **Synonym radar:** "decrease" → "fall", "major" → "significant"।
- **Not Given ≠ False:** টেক্সটে নাই মানেই Not Given।
- **Word limit:** "TWO WORDS" মানে এক বা দুই, তিন না।
- **Guess if stuck:** খালি রাখবেন না, সময় শেষে best guess।

---

## Pauline Cullen Reading Insight

Cullen-এর *The Key to IELTS Success* বলে: রিডিং-এর কোর হলো **micro-skills** — প্রতিটা question type-এর ছোট ছোট স্কিল আলাদা (skimming, scanning, paraphrasing, locating info)। শুধু "ভোকাবুলারি বাড়ানো" না, টেকনিক রপ্ত করুন। আর authentic IELTS material-এ "answer without reading guess করা যায় না" — তাই পড়তে হবেই, কিন্তু স্ট্রাটেজিক ভাবে।

## কমন প্রবলেমস: BD/Asian স্টুডেন্টস ফেস + সলুশন

**১. রিডিং স্লো → লিসেনিং-ও আটকায়**
- **সমস্যা:** রিডিং আর লিসেনিং দুইটাই "ডিকোডিং" স্কিল। ওয়ার্ড রিকগনিশন স্লো হলে লিসেনিং-এও ল্যাগ করে।
- **সলুশন:** phonics gap ঠিক করুন (নিচের #২) → রিডিং স্পিড বাড়ে → লিসেনিং নিজে থেকেই।

**২. Word decoding slow (phonics gap)**
- **সমস্যা:** বাংলা স্পিকারদের /θ/, /ð/, /v/, /w/, /r/-/l/, short/long vowel-এর গ্যাপ থাকে → ওয়ার্ড চিনতে দেরি।
- **সলুশন:** **Duolingo English (ফ্রি) minimal pairs** রোজ ১০ মিনিট। এটা পারসেপশন + উচ্চারণ দুইটাই ঠিক করে।

**৩. Type of expression না বোঝা**
- **সমস্যা:** টেক্সটের সিগন্যাল ওয়ার্ড (however, therefore, in contrast, similarly) না চিনলে স্কিম-স্ক্যান ভাঙে, কোথায় যাবেন বুঝেন না।
- **সলুশন:** **BBC Learning English ৬ Minute Vocabulary**-এর signposting/listing/contrast লিস্ট রপ্ত করুন। এগুলো টেক্সটের "রাস্তা" দেখায়।

**৪. আইসোলেটেড ভোকাব লিস্ট**
- **সলুশন:** BBC contextual vocabulary — আইসোলেটেড লিস্ট বাদ দিন। কনটেক্সটে শিখুন।

**৫. প্যানিক + আঙ্কেলকুলেশন**
- **সলুশন:** **Breathing 333** (inhale 3, hold 3, exhale 3, hold 3)। আর math মনে রাখুন: **Academic Reading-এ ৩০/৪০ = ৭** → ১০টা ভুল করলেও ৭ আসে। তাই একটা কোশ্চেন মিস করলে থেমে থাকবেন না, পরেরটায় যান।
